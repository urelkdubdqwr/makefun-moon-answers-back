One line, 1 to 240 characters, in the voice of the Moon replying to the wishes and howls of everyone staring up at it. main.py writes it to /output/entry.txt.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
